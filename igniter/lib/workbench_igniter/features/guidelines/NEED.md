# guidelines

Your team agreed how it writes Elixir, and the agreement lives somewhere nobody opens.

**Before:** the conventions are a link in a wiki, or in another repository's README: the people who most need them — whoever joined last week — never find them, and reviews re-litigate the same commas.

**After:** the guide is a page of the project's own documentation, beside the modules it talks about, in the docs site with everything else.

**Not for:** enforcing anything — that is [credo](../credo/)'s job. This puts the text where it is read; nothing checks the code against it.
