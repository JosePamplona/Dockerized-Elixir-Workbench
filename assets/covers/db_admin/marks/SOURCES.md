# The four admins' marks

Composited onto the cover by `covers.py`, never asked of the generator.
Each is the project's own file, unaltered, taken on 2026-09-19 from its
repository; used to name the tool the box installs.

| File | From |
| --- | --- |
| `pgadmin.svg` | pgadmin-org/pgadmin4, `web/pgadmin/dashboard/static/img/welcome_logo.svg` |
| `pgadmin-symbol.png` | pgadmin-org/pgadmin4, `web/pgadmin/static/img/logo-256.png` |
| `phpmyadmin.svg` | phpmyadmin/data, `brand/phpMyAdmin-Logo-Default.svg` |
| `phpmyadmin-symbol.svg` | phpmyadmin/data, `brand/phpMyAdmin-Logo-Symbol.svg` |
| `adminer.svg` | vrana/adminer, `adminer/static/logo.svg` |
| `cloudbeaver.svg` | dbeaver/cloudbeaver, `webapp/packages/core-app/public/icons/product-logo_light.svg` |
| `cloudbeaver-symbol.svg` | dbeaver/cloudbeaver, `webapp/packages/core-app/public/favicon.svg` |

`art/logos.jpg`, the first reference, is not a source: it shows
DBeaver's mark for CloudBeaver, phpMyAdmin's legacy schooner, and
Adminer's cylinder without its `<?`.

The strip `covers.py stamp --marks` lays on is the four numbered PNGs,
rendered from the files above with Inkscape and trimmed, in the order
of the box's option: `1-pgadmin.png` (the PNG as it is),
`2-phpmyadmin.png`, `3-adminer.png`, `4-cloudbeaver.png` — the last
without the white square its favicon SVG draws behind the beaver.
