# exdoc — six proposals

Written from the cartridge's README and nothing else. The era block of
the winner goes into `cover.prompt.txt` verbatim; what follows is the
hero paragraph each era would put in it.

## The register

**Hospitable** — the mechanism receives whoever arrives and has already
laid everything out for them: the reference read off the code, the
guide, the diagram, the reports, all one door away. Subtitles invite
(`ONE URL AWAY`, `START HERE`). Not on the landmark list; added for
this cartridge, one line, no medium.

Title `EXDOC`. Subtitle `ONE URL AWAY` — the README's own phrase. The
one string a hero may carry at foreground size is the address,
`/dev/docs`: it is the mechanism's whole promise, and the generator
lands strings at that size.

## The recommendation

**1 — the early carton.**

The reason comes from the cartridge: what exdoc makes is printed
reference matter — module pages, a style guide, a database diagram,
test reports — read off the code and set as pages, and the carton
entry is the one era whose art *is* printed reference matter: a
schematic in two-colour offset on uncoated board. The six cards on one
ring are the six pages the other features send to the hub, and the
count is of separate bodies, which the generator keeps. The runner-up
is 5, the same convergence drawn as six tablets orbiting the hub, if
the shelf wants chrome.
