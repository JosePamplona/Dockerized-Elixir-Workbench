# version_manager — back copy

Set in the front's register (fitting). Every string here is composited
as typeset text, never generated, so it can be any size and is exact.
The blurb is the cartridge's NEED.md — its sentence, its before and its
after, in the reader's second person; the features, the quote and the
requirements come from its DESIGN.md — the decisions with what each one
buys, a source's own words, what it was verified with; the install line
from its README. The version is not here: the tool reads it off the
cartridge's CHANGELOG.md.

## Headline

ONE HOST. EVERY ELIXIR.

## Blurb

Your machine has one Elixir: the last one you installed. The project
from two years ago and the one from this morning share it, and
switching is something you do by hand, or forget to. This cartridge
writes the file your version manager reads. Step into the project and
mix, iex and your editor run its Erlang and its Elixir; step into the
next, and they run that one's.

## Features

- Versions read off what runs the project
- Elixir built for your Erlang, not the oldest
- One file serves asdf and mise alike

## Quote

Whenever .tool-versions file is present in a directory, the tool versions it declares will be used in that directory and any subdirectories. — asdf documentation

## Requirements

REQUIRES: ASDF OR MISE ON THE HOST
VERIFIED WITH MISE 2026.9, ASDF 0.14

## Install
