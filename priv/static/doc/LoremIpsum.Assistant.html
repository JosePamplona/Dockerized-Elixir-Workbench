        View Source LoremIpsum.Assistant (Lorem Ipsum v0.0.0)

        The Assistant context handles operations related to user conversations with the OpenAI API.

        This module provides functionality for managing conversations, including creating, retrieving, continuing, and deleting them. It ensures that all operations are scoped to the authenticated user, maintaining proper access control.

        This module acts as the bridge between user interactions and the OpenAI API, while also persisting conversation data securely in the database.

        Summary

        Functions

        continue_conversation(attrs, current_user)

        Sends a request to the OpenAI API to process all conversation messages, including the new ones. If the request is successful, it saves the messages to the conversation and returns the updated conversation.

        create_conversation(attrs, current_user)

        Sends a request to the OpenAI API to process all conversation messages. If the request is successful, it saves the messages to the conversation and returns the newly created conversation.

        delete_conversation(attrs, current_user)

        Deletes a conversation if it belongs to the given user.

        get_conversation(attrs, current_user)

        Retrieves a single conversation with all its messages if it belongs to the given user.

        list_conversations(attrs, current_user)

        Returns the list of conversations belonging to the given user.
