# pgadmin

You want to look at the database, not type SQL blind into `psql`.

**Before:** `./wb.sh bash`, `psql`, `\dt`, and a query you retype for every table.

**After:** pgAdmin in the browser, already connected to the workspace's Postgres, on its own port beside the app's.

**Not for:** projects on another database, or on SQLite — pgAdmin administers Postgres alone.
