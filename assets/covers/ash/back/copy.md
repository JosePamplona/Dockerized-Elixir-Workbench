# ash — back copy

Set in the front's register (commissioning). Every string here is
composited as typeset text, never generated, so it can be any size and
is exact. The blurb, the features, the quote and the requirements come
from the cartridge's DESIGN.md — the problem, the decisions with what
each one buys, a source's own words, what it was verified on; the
install line from its README. The version is not here: the tool reads
it off the cartridge's CHANGELOG.md.

## Headline

YOU ORDER. THEY BUILD.

## Blurb

Ash is not a library you add to mix.exs: it rewrites your repo, your
config, your test case, and raises a domain with its resources and
migrations. By hand that is a day of reading. Every Ash package ships
its own builder, and the site gives you one line to set them all
going. This cartridge writes that line from your order, hands it over,
and builds nothing itself.

## Features

- Postgres, JSON:API, GraphQL, auth: pick, and it is one line
- Six builders on the first run, and nothing to undo
- Your database wiring stays yours; the secret lands in .env
- Ask for more later, and only the new is built
