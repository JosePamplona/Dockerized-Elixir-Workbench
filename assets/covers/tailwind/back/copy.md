# tailwind — back copy

Set in the front's register (reverent), shared by the seven base
cartridges. Every string here is composited as typeset text, never
generated, so it can be any size and is exact. The blurb is the
cartridge's NEED.md — its sentence, its before and its after, in the
reader's second person; the features, the quote and the requirements
come from its DESIGN.md (the engine's from mailer's) — the decisions
with what each one buys, a source's own words, what it was verified
with; the install line from its README. The version is not here:
the tool reads it off the cartridge's CHANGELOG.md. The screenshots are
not taken yet: the captions say what each one has to show.

## Headline

EVERY CLASS, ALIVE AGAIN.

## Blurb

Your markup was written for Tailwind, and a frozen stylesheet is
styling it: classes in every template that mean nothing, eighty
kilobytes that never change. This cartridge brings back the pipeline
phx.new would have given you, and the markup that comes with it. The
classes rebuild on save; heroicons, daisyUI and a light, dark or system
theme arrive in the layout. Its build needs html.

## Features

- The markup changes come with the pipeline
- The frozen stylesheet goes, unless you rewrote it
- Says so when html must come first

## Quote

The generated markup will still include Tailwind CSS classes, those are left-in as reference for the subsequent styling of your layout and components — mix help phx.new, on --no-tailwind

## Requirements

REQUIRES: PHOENIX 1.8, HTML FOR THE BUILD
BUILDS WITH TAILWIND 4.3.0, DAISYUI 5.5.20
