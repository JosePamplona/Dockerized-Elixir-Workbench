# tailwind

Your markup was written for Tailwind, and a frozen stylesheet is styling it.

**Before:** classes in every template that mean nothing, an 80 kB `default.css` snapshot that never changes, no theme, no icons.

**After:** the classes come alive, rebuilt on save; heroicons as CSS classes, daisyUI's components, a light/dark/system toggle in the layout.

**Not for:** a project without html — the build needs LiveView's compiler, which html brings; the insert says so.
