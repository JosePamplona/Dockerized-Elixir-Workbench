# mishka_chelekom — back copy

Set in the front's register (wayfinding). Every string here is
composited as typeset text, never generated, so it can be any size and
is exact. The blurb comes from the cartridge's NEED.md — its sentence,
its Before and its After — and, for the half the front is about, from
its DESIGN.md's account of the MCP server; the features from the
DESIGN's decisions, each with what it buys; the requirements from what
the DESIGN's evaluation ran on — and no client is named in them, since
the evaluation drove the server with `curl` and not with one; the install line from its README. The
version is not here: the tool reads it off the cartridge's
CHANGELOG.md. No quote: the DESIGN quotes no source on what the box is
for, and the one line that would do — the library's own, on agents
that guess — was read through a summarizer and is not verbatim.

## Headline

STOP GUESSING. ASK.

## Blurb

You want ready-made components that are your own code: every card,
timeline and navbar written by hand, or dressed in class names whose
behaviour is still yours to write. This cartridge generates them into
your project, yours to edit. And when an AI tool writes your pages, it
no longer guesses what a component takes: it asks your project, which
answers with the components it really has.

## Features

- All 74 components, or only the ones you name
- An MCP server on your app's own port
- One task writes the file your AI tool reads
- daisyUI out, if these are your one set

## Requirements

REQUIRES: PHOENIX 1.8, LIVEVIEW 1.2, TAILWIND 4
SERVES MCP OVER HTTP, IN DEV ONLY

## Install

`./wb.sh add mishka_chelekom --mcp`
