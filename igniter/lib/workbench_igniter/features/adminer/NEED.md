# adminer

Your project isn't on Postgres, and pgAdmin said no.

**Before:** the server's own client in a shell — `mysql`, `sqlcmd`, `sqlite3` — and a query retyped for every table.

**After:** Adminer in the browser, on its own port beside the app's, its login form already pointing at the workspace's database whatever the adapter: the password is all you type.

**Not for:** going deep into Postgres — plans, server activity, the dashboards — which is pgAdmin's, the collection's pick.
