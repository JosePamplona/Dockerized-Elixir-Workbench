# Credo's own mark

Composited onto the cover by `covers.py stamp --mark`, never asked of
the generator. The project's own file, unaltered, taken on 2026-09-20;
used to name the one tool the box installs.

| File | From |
| --- | --- |
| `credo-symbol.png` | rrrene/credo, `assets/credo-logo.png` — the symbol alone, 338×336 |
| `credo-with-trail.png` | rrrene/credo, `assets/credo-logo-with-trail.png` — the logo `mix.exs` declares for the docs (`logo:`), 486×312; the same file hexdocs serves at `credo.hexdocs.pm/assets/logo.png` |
| `1-credo.png` | `credo-symbol.png` as it is — what `--mark` lays on |

The symbol is what goes on the square: it is square, and the trail
bleeds off its own left edge, so inside a rounded square it reads as a
crop rather than as a logo. The trail version is kept because it is the
file the project declares as its logo, and because a later face — a
back plate, a wider slot — may want it.

**The mark carries the badge's fact.** It is a dark slate rounded square
with five coloured bars laid across it, and Credo colours its five check
categories in exactly five colours in its own output
(`lib/credo/cli/output.ex`: consistency cyan, readability blue, design
olive, refactor yellow, warning red). The logo is the five groups drawn
as five lines of code — which is why it replaces the typeset `5 GROUPS`
flash rather than standing beside it, and why the blackboard's column of
`[C] [D] [F] [R] [W]` is the same fact a third time, in letters.
