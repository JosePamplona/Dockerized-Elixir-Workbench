# clustering — six proposals

Written from the cartridge's README and nothing else. The era block of
the winner goes into `cover.prompt.txt` verbatim; what follows is the
hero paragraph each era would put in it.

## The register

**Ominous** — the mechanism is superior to the viewer, and withholds:
replicas of one image boot, each announces its name, and by one DNS
lookup they find each other without a wire between them, and talk
among themselves. Subtitles threaten.

Title `CLUSTERING`. Subtitle `THEY FIND EACH OTHER` — what DNSCluster
does, literally; *they speak as one* was a balancer's line, not a
cluster's. Accent EGA yellow (#FFFF55), the colour of those screens, with magenta grid lines. Badge `PROD ONLY`: the boot script only runs from a
release, and the shelf's badges say where a cartridge lives (`DEV &
TEST`, `DEV ONLY`). No furniture: the era's format mark said nothing
about the feature. The one string a hero
may carry at foreground size is a node name in the form the release
boots with, `app@172.25.0.4` — on one body only; the other three carry
nothing, since digits below foreground size flip.

The counts that are true: **four** replicas (`--deploy scaled`), one
name that answers with every address, and no cords — discovery is a
lookup, not a wire. Where an era wants links drawn, they are light,
and counted where they leave a body: *three leave every one*.

## The recommendation

**2 — the home computer.**

The reason comes from the cartridge: what clustering guarantees is
sameness — every replica runs the same image with the same baked
cookie, and differs from the others only by the address in its name.
The home computer entry draws sameness by construction: a limited
palette cannot make four monoliths different, and its grid floor is a
plane of addresses before it is anything else. The beams meeting at one
point above the square are the one DNS name that answers with every
address, drawn without a cord between the replicas, which is how
discovery works. The runner-up is 6, the same four bodies as beacon
towers, if the shelf can take a second big box.
