# changelog — back copy

Set in the front's register (inaugural). Every string here is
composited as typeset text, never generated, so it can be any size and
is exact. The blurb is the cartridge's NEED.md — its sentence, its
before and its after, in the reader's second person; the features, the
quote and the requirements come from its DESIGN.md — the decisions with
what each one buys, a source's own words, what it was verified with;
the install line from its README. The version is not here: the tool
reads it off the cartridge's CHANGELOG.md.

## Headline

THE RECORD STARTS HERE.

## Blurb

Your project has a version number, and no versioning. mix.exs has said
0.1.0 since the generator wrote it, maybe for years, and what changed
between one build and the next is somewhere in the git log. This
cartridge opens the record at the version you are on today. From here
on every change is written down, and a release is a moment.

## Features

- Opens at your version, new or years in
- Written by hand, for whoever reads it
- One command cuts a release: number, log, badge
- A number Mix cannot compile is never written

## Quote

Don’t let your friends dump git logs into changelogs. — Keep a Changelog

## Requirements

REQUIRES: A MIX PROJECT, AND A VERSION IN IT
VERIFIED ON PHOENIX 1.8, ELIXIR 1.19 / OTP 27
