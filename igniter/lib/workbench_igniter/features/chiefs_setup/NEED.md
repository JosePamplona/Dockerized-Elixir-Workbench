# chiefs_setup

Your project is vanilla and the shelf is full: you want the workbench's own picks in, without choosing box by box.

**Before:** a stock `phx.new` project boots in the workbench, and every capability is a decision — which API, which docs, which coverage, which checks — made ten times, in the right order, every time you start something.

**After:** one box inserts the chief's picks — the dep-only quintet, REST or GraphQL as you say, coveralls, the ExDoc site, the enhancements base and the healthcheck endpoint — each as its own commit, so `eject` still takes any one of them out alone.

**Not for:** a project that wants its own combination — the picks are fixed on purpose: if you would uncheck one, skip the box and add cartridges à la carte. A member's fine options (coverage theme, probe path) are set on the member, never here.
