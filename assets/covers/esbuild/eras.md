# esbuild — six proposals

Written from the cartridge's NEED.md first, then its README and
DESIGN.md, and nothing else. The era block of the winner goes into
`cover.prompt.txt` verbatim; what follows is the hero paragraph each
era would put in it.

## The need

*Your page needs JavaScript, and there is no bundler to write it in.*
Before: a placeholder `app.js` that is a comment telling you which
scripts to copy by hand. After: `app.js` bundled on every save,
`import` a plain word again, one file to ship.

## The register

**Heroic** — the mechanism triumphs, and the viewer is invited to
join it: write the import, and it is there. Subtitles command.

Title `ESBUILD`. Subtitle `JUST IMPORT IT`. Badge `JS/APP.JS` — the
entry, the file the need names. Accent **arc yellow** or the era's
nearest, unused on the shelf. No furniture unless the era's own
column has one.

The counts that are true: **one** placeholder replaced; **one** entry
file; **one** bundle out; **three** aliases; rebuilt on **every**
save. The strings a hero may carry at foreground size, one per hero:
`import`, `app.js`, `--watch`, `bundle`. Where a comment appears, it is
the placeholder; where a machine, it is the bundler.

## The recommendation

**4, the console entry.** The need is *write the word and it is
there*, and that is a heroic act with a person doing it: a hand on the
keys, the bolt from the screen to the bars. The carton's machine
explains the same thing; the console era lets the viewer feel it.

The shelf as it stands: clustering manual from a home-computer start;
healthcheck2 manual from an editorial start; exdebug console; exdoc
big box; ash big box; coveralls, healthcheck and enhancements starting
over. Console has one cover, and ecto's and html's proposals name it
too — three would be the signal. If esbuild yields, 2 — the beam from
the terminal on the grid — is the same act in flat solids, and the
home-computer era has only a manual descendant.
